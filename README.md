# Software QA / SQA 포트폴리오

## 교육 목적

약 2년간의 게임 QA 실무 경험을 바탕으로 소프트웨어 QA 분야로 역량을 확장하기 위해 진행한 10일 집중 학습 및 실습 포트폴리오입니다.

기존의 기능 검증, 테스트 케이스 작성, 결함 분석 경험에 API 테스트, 데이터베이스 검증, 프로그래밍 역량을 더하는 것을 목적으로 진행하였습니다.

## 교육 목표

- **Postman**: REST API 구조 이해 및 JavaScript를 활용한 응답 자동 검증
- **SQL**: 데이터 조회, 테이블 간 관계 분석 및 데이터 정합성 검증
- **Java**: 프로그래밍 기초 학습 및 테스트 판정 로직 구현
- **QA 실무 역량**: 정상·예외 테스트 설계, 기대 결과와 실제 결과 비교 및 테스트 결과 문서화

## 10일차 종합 실습

**[Day 10 — API 및 게시글 데이터 정합성 검증](Day10_Integration_QA)**

1~9일차에 학습한 Postman, SQL, Java를 활용하여 사용자 및 게시글 데이터를 검증하는 종합 실습을 진행하였습니다.

- **Postman**: 사용자·게시글 API의 상태코드, 필수 필드, 데이터 관계 및 예외 응답 검증
- **SQL**: SQLite 데이터를 이용한 사용자 참조 관계, 제목 유효성 및 데이터 정합성 검증
- **Java**: 동일한 검증 규칙을 구현하고 기대 결과와 실제 결과를 비교하는 자동 판정 로직 작성

**실습 결과:** Postman 4개 TC 검증, SQL 6개 쿼리 검증, Java 9개 테스트 PASS

공개 API와 별도로 구성한 실습용 데이터베이스를 사용하였으며, 실제 서비스의 데이터 저장을 검증하는 E2E 테스트는 포함하지 않았습니다.
