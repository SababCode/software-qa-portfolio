# Software QA / SQA 포트폴리오

게임 QA 실무 경험을 바탕으로 소프트웨어 QA 역량을 확장하기 위한 학습 및 실습 포트폴리오입니다.

Postman, SQL, Java를 활용한 API 테스트, 데이터 검증 및 테스트 자동화 역량 강화를 목표로 합니다.

## 학습 목표

- **Postman**: REST API 테스트 및 자동 검증 스크립트 작성
- **SQL**: 데이터 조회 및 정합성 검증
- **Java**: 프로그래밍 기초 및 API 테스트 활용
- **QA 실무**: 테스트 설계, 결함 분석 및 검증 결과 문서화

## 학습 환경 및 기술

- **API 테스트**: Postman, JavaScript
- **데이터베이스**: SQLite, SQL
- **프로그래밍**: Java
- **버전 관리 및 문서화**: GitHub
