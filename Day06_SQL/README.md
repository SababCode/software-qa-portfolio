# Day 06 - SQL 심화 및 데이터 정합성 검증

## 학습 내용

- **EXISTS / NOT EXISTS**: 연관 데이터 존재 여부 확인
- **CTE (WITH)**: 복잡한 쿼리의 단계별 구성
- **JOIN**: 테이블 간 데이터 비교
- **TRANSACTION / ROLLBACK**: 데이터 변경 및 복구
- **데이터 정합성**: 누락·불일치 데이터 검증

## 실습 개요

사용자, 주문, 결제 데이터를 활용한 SQL 기반 데이터 정합성 검증

## 사용 환경

- **DBMS**: SQLite
- **SQL 도구**: DB Browser for SQLite
