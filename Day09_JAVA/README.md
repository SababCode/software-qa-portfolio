# Day 09 - Java 테스트 자동화 및 결과 리포트

## 1. 학습 목표

Java를 활용하여 여러 테스트 케이스를 자동 실행하고, 상태 코드와 응답 시간을 검증하는 테스트 프로그램을 구현했습니다.

테스트 결과를 PASS, FAIL, ERROR로 구분하고, 예외 처리 및 결과 집계를 통해 테스트 자동화의 기본 구조를 학습했습니다.

## 2. 구현 기능

- **테스트 자동 실행**: ArrayList와 반복문을 활용한 다중 테스트 케이스 실행
- **상태 코드 검증**: 실제 HTTP 상태 코드와 기대 상태 코드 비교
- **응답 시간 검증**: 1,000ms 이하 응답 시간 검증 및 경계값 처리
- **예외 처리**: 음수 응답 시간 발생 시 IllegalArgumentException 처리
- **테스트 독립성**: 예외가 발생해도 다음 테스트 케이스가 계속 실행되도록 구현
- **결과 관리**: PASS, FAIL, ERROR 집계 및 개별 TC 결과 저장
- **리포트 생성**: PASS RATE, OVERALL RESULT, COUNT VALID 출력

※ 실제 API 요청 대신 사전에 정의한 응답 데이터를 활용하여 검증 로직을 구현했습니다.

## 3. 프로젝트 구조

| 파일 | 역할 |
|---|---|
| `App.java` | 테스트 케이스 생성 및 자동 실행 |
| `TestCase.java` | 테스트 케이스별 입력 데이터 관리 |
| `ApiValidator.java` | 상태 코드 및 응답 시간 검증 |
| `TestResult.java` | 테스트 결과 저장, 집계 및 리포트 출력 |

## 4. 테스트 케이스 및 기대 결과

**검증 조건**

- HTTP 상태 코드가 기대값과 일치해야 PASS
- 응답 시간이 0~1,000ms 범위여야 PASS
- 응답 시간이 음수이면 ERROR 처리
- 상태 코드 또는 응답 시간 조건을 만족하지 않으면 FAIL 처리

| TC | 실제 코드 | 기대 코드 | 응답 시간(ms) | 기대 결과 |
|---|---|---|---|---|
| TC01 | 200 | 200 | 350 | PASS |
| TC02 | 201 | 201 | 950 | PASS |
| TC03 | 400 | 200 | 500 | FAIL (STATUS) |
| TC04 | 404 | 404 | 1200 | FAIL (RESPONSE TIME) |
| TC05 | 500 | 200 | -100 | ERROR |
| TC06 | 200 | 200 | 1000 | PASS |
| TC07 | 200 | 200 | -1 | ERROR |
| TC08 | 500 | 200 | 400 | FAIL (STATUS) |

※ 음수 응답 시간은 유효하지 않은 데이터로 판단하여 상태 코드 검증 결과와 관계없이 ERROR로 처리했습니다.

## 6. QA 관점의 검증 및 개선 사항

### ① 테스트 결과 분리

상태 코드 불일치와 응답 시간 초과를 구분하여 실패 원인을 확인할 수 있도록 구현했습니다.

또한 유효하지 않은 응답 시간은 일반적인 FAIL과 구분하여 ERROR로 처리했습니다.

### ② 테스트 독립성 확보

try-catch를 각 테스트 케이스 실행 과정에 적용하여 특정 테스트에서 예외가 발생하더라도 이후 테스트가 정상적으로 실행되도록 구현했습니다.

### ③ 결과 집계 정합성 검증

테스트 결과 집계 과정에서 FAIL 개수가 누락되는 문제를 발견하고 수정했습니다.

이후 다음 조건을 추가하여 결과 집계의 정합성을 검증했습니다.

`TOTAL = PASS + FAIL + ERROR`

### ④ 클래스별 역할 분리

테스트 데이터, 검증 로직, 테스트 실행 및 결과 관리를 별도 클래스로 분리하여 코드의 가독성과 유지보수성을 개선했습니다.

## 7. 학습 결과

Java의 클래스, 메서드, ArrayList, 반복문 및 예외 처리를 활용하여 기본적인 테스트 자동화 프로그램을 구현했습니다.

단순히 PASS/FAIL을 출력하는 것에서 나아가 실패 원인 구분, 예외 처리, 결과 저장 및 집계 정합성 검증을 경험했습니다.

이를 통해 QA 관점에서 테스트 결과의 정확성과 신뢰성을 확보하는 과정의 중요성을 학습했습니다.
